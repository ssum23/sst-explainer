# ⑤ 정보 탭 기준값·문구 출처

## 1. 가장 큰 것 — 위기경보가 **4단계가 아니라 5단계**다

**§5 정보 화면 목업이 「관심 → 주의 → 경계 → 심각」 네 칸으로 그려져 있다. 다섯이다.**

| 단계 | 발령 기준 |
|---|---|
| **관심** | 폭염(고수온) **대책기간 (5.15 ~ 9.30)** |
| **주의** | 고수온 **예비특보**가 발표되었을 때 |
| **경계** | 고수온 **주의보 해역이 4개 이상** / 수산생물 피해 발생이 **예상**될 때 |
| **심각 Ⅰ** | 주의보 해역 **15개 이상** / 경보 해역 **8개 이상** / 특보 기간 중 수산생물 **피해 발생** |
| **심각 Ⅱ** | 경보 해역 **30개 이상** / 특보 기간 중 **대규모** 수산생물 피해 발생 |

**§16의 「위기경보 '심각' 단계의 세분화 여부」 — 세분화되어 있다.**
2024·2025·2026년 해양수산부 보도자료가 실제로 「심각Ⅰ」로 발령했고, 언론도 5단계로 적는다.

### 근거 신뢰도 — 화면에 싣기 전에 원문 대조가 필요하다

기준 표의 직접 출처는 **나무위키**다. 기관 원문이 아니다. 다만 셋으로 교차 검증됐다.

1. 전라남도 해양수산과학원 PDF의 검색 색인 제목이 **「판단기준 … 폭염(고수온) 대책기간 (5.15~9.30) 관심」**으로 문자 그대로 일치한다 (본문은 접속 불가)
2. **2026년 실제 발령 이력과 전부 맞는다** — 7/14 예비특보 21개 → 주의 · 7/21 주의보 8개(≥4) → 경계 · 7/30 경보 6개 + 주의보 16개(≥15) → 심각Ⅰ
3. 이미 알고 있던 「경계 = 주의보 4개 이상」과 일치

**§5 설계 조건 5가 「문구의 출처를 문서에 남긴다」고 했으므로, 나무위키를 출처로 화면에 실을 수 없다.**
맥에서 아래를 열어 원문을 확보해야 한다.

- 전남 해양수산과학원 「고수온 위기경보 단계별 조치사항」 `ofsi.jeonnam.go.kr/bbs/ofsi/48/8813/download.do`
- 해수부 「올여름 고수온·적조 단계별로 대응한다」 `mof.go.kr/doc/ko/selectDoc.do?docSeq=57204&menuSeq=971&bbsSeq=10`
- 해수부 「고수온 위기경보 '심각Ⅰ' 단계 발령」 `korea.kr/briefing/pressReleaseView.do?newsId=156700580`

## 2. 뜻밖의 소득 — §2의 「대책기간 5/15~9/30」에 근거가 생겼다

**위기경보 「관심」 단계의 기준이 문자 그대로 `폭염(고수온) 대책기간 (5.15~9.30)`이다.**

§2는 「수산과학원 대책기간이 매년 동일한지는 확인되지 않았다」고 적고, 그 의존을 끊기 위해
분석 기간을 「우리가 정한 것」으로 재규정했다(§16에도 미확인으로 올라 있다).

**이 재규정은 그대로 두는 것이 맞다.** 다만 §2에 한 줄 붙일 수 있다 —
**해양수산부 위기경보 「관심」 단계가 같은 날짜를 대책기간으로 쓴다.**
즉 우리가 정한 구간이 제도상 대책기간과 **우연히 같은 것이 아니라 같은 근거를 공유**한다.

**단, 원문 대조 전까지는 쓰지 않는다.** 나무위키 경유 정보다.

## 3. 고수온 특보 3단계 — 언론 출처만 확보됐다

| 단계 | 기준 | 확인 수준 |
|---|---|---|
| 예비특보 | 수온 **25℃** 도달 또는 도달 예상 | 언론 다수 (2024·2025·2026) |
| 주의보 | 수온 **28℃** 도달 또는 도달 예상 | 언론 다수 |
| 경보 | **28℃ 이상 3일 이상 지속** 또는 지속 예상 | 언론 다수 |

**§5 목업의 세 줄과 일치한다.** 다만 전부 언론이고 기관 원문을 못 열었다.
`§5 설계 조건 5`를 충족하려면 해수부·수과원 보도자료 원문이 필요하다.

## 4. 확인 못 한 것 — 셋 다 §16에 이미 올라 있던 것

| 항목 | 결과 |
|---|---|
| **예비특보 25℃가 언제부터인가** | **확인 못 함.** 2024-08-05에 이미 운영 중이었던 것만 확인. 「2024년 6월부터」를 뒷받침하는 문서를 못 찾았다 |
| **2024년 이전의 기준값** | **확인 못 함.** 예비특보 제도가 없었는지, 다른 온도였는지 모두 미확인. §16 「2024년 이전 예비특보 기준값 — 미확인」이 그대로 남는다 |
| **28℃가 일평균인가 일 최고인가** | **확인 못 함.** 여러 경로로 찾아도 어느 문서도 밝히지 않는다 |

**세 번째는 「못 찾았다」가 아니라 성과다.** §2가 「수산과학원 특보 문구는 일평균인지 일 최고인지
명시돼 있지 않다」고 적고 그 위에 **우리의 선택**(채점 분류는 일 최고)을 세웠는데,
**독립적으로 다시 찾아도 없다는 것이 확인됐다.** §2의 전제가 버틴다.

§16의 「국립수산과학원 특보 페이지 주소 — 지금은 기관 대표 주소를 링크한다」.

# ⑥ 지도 배경 이미지 출처

## 6. 가장 큰 것 — PRD가 고려하지 않은 규제가 있다

§5는 브이월드·국립해양조사원·국토지리정보원을 「출처가 깨끗한 것」으로 적었다.
**저작권은 그럴 수 있으나 별개의 규제가 있다.**

> 「측량성과 국외반출 허가심사 운영규정」 제3조 심사 대상:
> **"기본측량성과 및 공공측량성과를 활용(편집, 가공, 추출 등)한 지도 등의 공간정보"**

**GitHub은 미국 서버이므로 국외반출에 해당한다.** 브이월드 화면을 bbox로 잘라
공개 저장소에 커밋하는 행위가 문자 그대로 이 문구에 걸린다.

제외 규정이 있으나(공간정보관리법 시행령 제16조) **원문을 확인하지 못했다.**

**§5의 「저작권 조건」 절에 이 항목이 없다. 추가해야 한다.**
브이월드·국토지리정보원을 쓰려면 국토지리정보원에 서면 확인이 필요하다.

## 7. 추천 — OpenStreetMap. 단, 타일을 긁으면 안 된다

| | |
|---|---|
| 이용 조건 | 데이터는 **ODbL**. 렌더링한 이미지는 **Produced Work**이고 원문이 `"release your map under any license that you like"` — **공개 저장소 커밋 가능**. 상업/비상업 구분 없음 |
| 국외반출 | **무관** — 해외 서버 원본이다 |
| 키 | **불필요** |
| 해안선 품질 | **실측했다.** 지정 bbox 안에 `natural=coastline` **way 582개 · 노드 29,501개**. 85×89 km에 정점 3만 개면 태안반도 리아스식 해안과 가로림만 갯골까지 나온다 |

**화면에 넣을 출처 문구 (약관 요구 충족):**

```
© OpenStreetMap contributors — 데이터 제공: ODbL
https://www.openstreetmap.org/copyright
```

### 하면 안 되는 방법

`tile.openstreetmap.org`에서 타일을 받아 이어붙이는 것은 **타일 이용정책 위반**이다 —
원문이 `"Offline use is not permitted on tile.openstreetmap.org"`이고 배포용 타일 아카이브 제작을 금지한다.

### 권장 경로

1. **Geofabrik 한국 추출본** `download.geofabrik.de/asia/south-korea.html` (271MB, ODbL, 가입 불필요)
   또는 **OSM 해안선 폴리곤** `osmdata.openstreetmap.de/data/coastlines.html`
2. **QGIS로 직접 렌더링.** 스타일 `openstreetmap-carto`는 **CC0**라 그대로 써도 된다
3. **도로를 빼고 육지·바다·섬만 남긴다** — 대상 사용자가 어민이므로 해안선이 도로망보다 중요하다

## 8. 투영법 함정 — §5의 bbox 절에 빠진 것

**§5가 확정한 `가로 : 세로 = 0.956 : 1`과 `viewBox 350 × 366`은 지상거리 비율이다.
이미지 비율은 투영법에 따라 다르다.**

| 투영 | 이미지 비율 | 변환식 |
|---|---|---|
| **EPSG:4326** 원본 그대로 | **1.1875 : 1** (가로로 납작) | 선형 |
| **EPSG:3857** 웹메르카토르 (일반 타일) | **0.9539 : 1** | 위도에 메르카토르 공식 필요 |

**웹메르카토르 이미지에 §5의 선형 변환식을 그대로 쓰면 위도 36.55° 부근에서
최대 2.8px ≈ 143 m 오차가 난다.** 양식장 위치를 표시하는 화면에서 무시할 수 없다.

**해법 — EPSG:4326으로 렌더링하되 출력 크기를 0.954 비율로 지정한다**
(표준위선 36.55°의 정거원통도법). 모양도 정상으로 보이고 변환식이 완전 선형이 된다.

```
x = (lon − 125.95) / 0.95 × W
y = (36.95 − lat)  / 0.80 × H
```

권장 크기 **2048 × 2147** 또는 **3000 × 3145**.

**§5는 「변환식은 `assets/geo.js`에 있다」·「bbox를 바꾸는 일은 그 파일 한 곳을 고치는 일이어야 한다」고
적었지만, 어느 투영으로 렌더링한 이미지를 전제하는지는 적지 않았다.** 그 한 줄이 있어야
3주차에 이미지를 교체할 때 관측점이 육지에 찍히지 않는다.

## 9. 검토했으나 접은 것

| 후보 | 판정 |
|---|---|
| **Natural Earth** | 퍼블릭 도메인이고 출처 표시도 불필요하나 **1:1000만 축척이라 가로림만이 구분되지 않는다** |
| **EOX Sentinel-2 cloudless** | **상업 이용은 유료 계약**이 필요하고 재배포·서브라이선싱이 금지된다 |
| **Copernicus Sentinel 위성영상** | 라이선스는 깨끗하고(`Contains modified Copernicus Sentinel data [Year]`) 10m 해상도라 양식장 뗏목까지 보이지만, **무료 계정이 필요하고** 위성영상은 개념도보다 읽기 어려울 수 있다. 시간이 남으면 검토 |
| 브이월드 · 국립해양조사원 · 국토지리정보원 | **이용약관 원문을 한 건도 못 읽었다.** 위 6절의 국외반출 문제까지 겹친다 |
